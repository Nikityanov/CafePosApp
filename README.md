# CafePOS

POS-приложение для кафе на .NET MAUI (Android / Windows / iOS / MacCatalyst) с локальной
базой SQLite, офлайн-работой и резервным копированием.

## Структура

```
Core/                 Платформонезависимое ядро (CafePos.Core, net10.0)
  Data/               AppDbContext (+ частичные файлы), DatabaseBootstrapper, DatabaseOptions
  Schema/             Собственный мигратор схемы (5 миграций, без EF-migrations)
  Services/           Каталог, заказы, чекаут, склад, черновики, бэкапы, экспорт
  Models/             EF-модели; деньги хранятся в копейках (INTEGER)
  Common/             Money, TextFormat, ObservableCollectionSync, Csv
Errors/               Исключения домена + UserMessages (тексты для оператора)
ViewModels/           MVVM; крупные VM разбиты на частичные файлы (.Commands.cs и т.п.)
  Catalog/            Формы карточек: товар, раздел, группа модификаторов, ингредиент
Views/                Страницы; code-behind максимально тонкий
Services/             Платформенные абстракции (диалоги, файлы, навигация) + реализации
Tests/                CafePos.Tests (xunit) — юнит- и интеграционные тесты ядра
```

## Ключевые решения

- **Деньги — только копейки (INTEGER).** SQLite хранит decimal как TEXT, из-за чего
  SUM/ORDER BY/сравнения ломаются. Модели отдают рубли через `Money.FromKopecks`.
- **Схема через собственный мигратор** (версии 1–5), миграция старых баз (TEXT-деньги,
  локальные метки времени) выполняется автоматически при старте (`DatabaseBootstrapper`).
- **DateTimeOffset не сортируется в SQL** (ограничение провайдера SQLite) — фильтрация
  делается в SQL, сортировка в памяти.
- **Чекаут атомарен**: заказ + списание склада + номер заказа в одной транзакции;
  номера уникальны в рамках смены (`Shift.NextOrderNumber` инкрементируется одним UPDATE).
- **Каталог**: товар с вариантами, рецептом (себестоимость), фото, часами доступности;
  soft-delete с восстановлением; CSV импорт/экспорт; массовая корректировка цен с записью
  в историю цен.
- **Формы каталога** — отдельные ViewModel (`ViewModels/Catalog/*`) и одна модальная
  страница `CatalogFormsPage`; список открывает её через событие `ShowFormRequested`.

## Сборка и тесты

```bash
dotnet build CafePosApp.csproj -f net10.0-windows10.0.19041.0   # или -f net10.0-android
dotnet test Tests/CafePos.Tests.csproj
```

Тесты запускаются на обычном net10.0 без MAUI: `TestHost` поднимает реальный
DI-контейнер ядра (`AddCafePosCore`) на временной базе SQLite и проверяет миграции 1–5
(включая обновление «старой» базы v1), чекаут, склад, черновики и бэкапы.

## Журналирование

`AppLog` пишет в `<AppData>/logs`, из «Настроек» журнал можно отправить через шеру;
бэкапы лежат в `<AppData>/backups` (автоматическая копия раз в сутки и при закрытии смены).
